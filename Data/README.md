# Dataset

This project uses synthetic B2B travel booking data created for portfolio and learning purposes.

The dataset represents a B2B travel platform and includes:

- Bookings
- Travel Agents
- Hotels
- Suppliers
- Destinations
- Payments
- Cancellations

## Dataset Size

The raw bookings dataset contained approximately 120,000 booking records.

## Data Quality Issues Included

The synthetic dataset intentionally contains realistic data-quality problems such as:

- Duplicate booking records
- Missing supplier IDs
- Mixed date formats
- Invalid room counts
- Invalid night values
- Zero or negative booking values
- Travel dates before booking dates
- Multiple payment transactions per booking
- Orphan cancellation records
- Multiple currencies
- Inconsistent country names

## Privacy and Usage

This dataset is fully synthetic and does not contain confidential or proprietary company data.

It was created specifically for Data Analyst portfolio development and learning.
